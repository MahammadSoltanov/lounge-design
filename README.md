# Responsive Landing Page Clone

A one-page responsive website built with pure **HTML**, **CSS**, and **JavaScript**.  
The layout is recreated from a public ThemeWagon design to demonstrate my ability to convert real-world UI designs into functional, clean, and responsive code.

## 🔗 Original Design Reference
**Lounge** – Free HTML5 Responsive Template by ThemeWagon


## ⚙️ Tech Stack
- **HTML5**
- **CSS3** (Flexbox & Grid)
- **Vanilla JavaScript**
- **Swiper.js** (integrated manually)
- **JSON** (for dynamic tab content)


## 📌 Purpose
This project was created for practice and portfolio demonstration — to showcase my ability to:

- Translate a static design into a fully responsive, interactive web page.  
- Write clean, maintainable, and reusable front-end code.  
- Integrate third-party libraries where appropriate.  


## ✨ Features I Built
- Animated UI for smooth, modern interactions.  
- **Custom navigation JavaScript** — scrolls smoothly to the clicked section heading.  
- **Custom tabs component** — loads content dynamically from a JSON file based on tab id.  
- **Custom dropdown** — built from scratch with JavaScript and CSS.  
- **Swiper.js integration** — implemented manually without boilerplate.  
- **Fully responsive design** — implemented from the design system, adapting to all screen sizes.  

## 📂 Code Reuse & Attribution
To save time on non-core features and focus on demonstrating relevant skills, I reused the following from the original source:

- **Design variables** (colors, typography, spacing) — essential for matching the original look.  
- **Preloader script** — a very small utility that doesn’t meaningfully demonstrate my coding ability.  
- **GLightbox library and its integration logic** — used for the gallery section to avoid spending hours on a feature that doesn’t showcase my core skills.  
  *(HTML, CSS, and JS for the gallery section are from the original source.)*
