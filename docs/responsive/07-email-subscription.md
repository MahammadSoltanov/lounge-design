# Email Subscription

The email subscription block is centered and includes a call-to-action text, an email input, and a subscribe button.

## Desktop

- Layout  
  - Center-aligned container  
  - Row 1: call-to-action text  
  - Row 2: flex container holding email input and subscribe button  

- Typography  
  - All text at 20px  

- Visual Behavior  
  - On empty submission, error message “Please enter a email adress” appears below the input  

## Tablet

- Layout  
  - Identical to desktop  

- Typography  
  - Remains 20px  

- Visual Behavior  
  - Remains the same as desktop  

## Mobile

- Layout  
  - Center-aligned container  
  - Row 1: call-to-action text  
  - Row 2: email input with the subscribe button wrapping beneath the input  

- Typography  
  - Remains 20px  

- Visual Behavior  
  - Remains the same as desktop
