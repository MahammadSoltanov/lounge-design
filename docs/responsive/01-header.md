# Header and Navigation

The header contains three key elements:
- **Logo** (left-aligned)
- **Navigation links** (centered)
- **Phone number** (right-aligned)



## Desktop (`> 1024px`)

### Layout
- 3-column grid:
  - Left: Logo
  - Center: Navigation links
  - Right: Phone number
- Even spacing across the full width

### Typography
- `font-size: 16px`
- `line-height: 32px`

### Interaction
- Active navigation link highlights with a lighter color

### Assets
- Logo image size: `108px × 28px`



## Tablet (`600px – 1024px`)

### Layout
- Logo remains left-aligned
- Navigation links and phone number are moved into a dropdown on the right

### Typography
- Dropdown text: `font-size: 20px`



## Mobile (`< 600px`)

### Layout
- Same as tablet layout
- Reduced spacing between elements

### Typography
- Dropdown text: `font-size: 16.25px`
